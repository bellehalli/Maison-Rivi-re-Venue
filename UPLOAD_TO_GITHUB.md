# Upload to GitHub

Upload **every item in this folder to the repository root**. Do not upload only `index.html`.

The root should contain:
- `index.html`
- `styles.css`
- `script.js`
- the other `.html` pages
- the entire `assets/` folder
- `.nojekyll`

For GitHub's browser uploader, drag the **contents of this folder**, not the outer folder itself.

All site asset paths are relative (for example `assets/images/11_neutral_crystal_ballroom.jpg`). The folder structure must remain unchanged.

All packaged files are below 25 MB so the browser uploader will accept them individually.
